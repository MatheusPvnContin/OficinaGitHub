# Oficina de GitHub

Material de apoio da oficina **"GitHub: conceitos básicos e versionamento na prática"**, desenvolvida no Projeto de Extensão II do curso de Sistemas de Informação do IFSP Votuporanga.

A oficina apresenta o Git e o GitHub para estudantes de cursos técnicos e superiores, inclusive para quem ainda não tem conta: criação e configuração da conta, fluxo de versionamento (`add`, `commit` e `push`), branches, Pull Requests e solução dos erros mais comuns.

## 📚 Conteúdo

- **Guia do participante:** conceitos essenciais, vocabulário e colinha de comandos
- **Slides de exibição:** acompanhamento de conceitos da plataforma durante a apresentação
