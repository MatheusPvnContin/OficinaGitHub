FLUXO PRINCIPAL

Do zero ao GitHub

terminal
cd minha-pasta-do-projeto
git init                      # transforma a pasta em repositório
git status                    # o que mudou? use sempre
git add .                     # prepara as mudanças
git commit -m "Primeiro commit"   # tira a foto do projeto
git branch -M main            # nomeia a branch como main
git remote add origin https://github.com/USUARIO/REPO.git
git push -u origin main       # envia para o GitHub

ROLLBACK

Commit errado: depende

Ainda só local

  • git commit --amend
  • Corrige a mensagem do último commit
  • git reset --soft HEAD~1
  • Desfaz o commit e mantém as mudanças

Já deu push

  • git revert abc1234
  • Cria um novo commit que desfaz
  • git push para publicar
  • Não reescreve o histórico publicado
21 / 36
GIT RESET

Os três jeitos de reset

SEGURO

--soft

Desfaz o commit. Mudanças ficam no staging.

PADRÃO

(sem opção)

Desfaz o commit. Mudanças ficam nos arquivos.

PERIGOSO

--hard

Desfaz o commit e apaga as mudanças.

HEAD~1 significa um commit antes do atual.

22 / 36
SOCORRO

Descartar e recuperar

terminal
git restore arquivo.txt            # descarta mudanças no arquivo
git restore --staged arquivo.txt   # tira do staging
git reflog                         # tudo o que o Git fez
git reset --hard HASH              # volta para um ponto do reflog

Subiu senha ou chave? Revogue a chave primeiro: apagar o arquivo não basta.

DÚVIDAS · ENVIO

Dúvidas frequentes: envio

Push rejeitado: fetch first?

Há commits no GitHub que você não tem. Rode git pull, depois git push.

Abriu um editor estranho no pull?

É a mensagem de merge. Salve e feche. No Vim: Esc, :wq, Enter.

O que é conflito de merge?

Duas pessoas mudaram a mesma linha. Escolha a versão, apague os marcadores, commit.

Commit e push: qual a diferença?

Commit salva no seu computador. Push envia para o GitHub.

32 / 36
DÚVIDAS · GIT

Dúvidas frequentes: Git

Pull ou fetch?

Fetch só baixa. Pull é fetch mais merge nos seus arquivos.

Commitei um arquivo que devia ignorar.

Adicione ao .gitignore e rode git rm --cached arquivo.

Aparece master em vez de main.

Sem problema. Use git branch -M main para casar com o GitHub.

Meus commits não aparecem no perfil.

Confira se o e-mail do git config é o da conta.

33 / 36
DÚVIDAS · GERAL

Dúvidas frequentes: geral

Por que não baixar o ZIP?

ZIP não tem histórico nem vínculo. Prefira git clone.

Apaguei a pasta do projeto!

Se estava no GitHub, basta um novo git clone.

Posso deixar o repositório privado?

Sim, em Settings. Lá também dá para excluir o repositório.

GitHub, GitLab ou Bitbucket?

Todos usam Git. O GitHub é o mais usado em portfólios.
